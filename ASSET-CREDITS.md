# Asset provenance

Windows 7 wallpaper and application/system icons are preserved locally for visual fidelity. Windows, Paint, their logos, and original UI artwork are Microsoft assets. The repositories below are archival sources, not claims that Microsoft's assets are public domain.

| Local asset | Upstream source |
| --- | --- |

| `public/assets/recycle.ico` | [bartekl1/windows-ui-assets](https://github.com/bartekl1/windows-ui-assets/blob/main/Icons/Windows%207/ico/shell32.dll/ICON32_1.ico) |

Ribbon tool glyphs, chrome, tray glyphs, and the Sticky Notes icon are original SVG/CSS approximations created for this project. No Lucide icons substitute for desktop or Paint icons.

`public/assets/louka-paint-portrait.jpg` is the user's supplied `GBUf5EOJ.jpg`, copied unchanged from Downloads for this portfolio. The current scene uses this portrait and the Paint application icon; the desktop artwork above is retained only as archived project material.
